## 頁面與內容

- `/`：品牌、空間入口、年度活動／展覽、地方筆記、到訪。
- `/about/`：空間背景、成立願景、四種使用規劃；未捏造營業時間或已開放服務。
- `/stories/`：可分類與搜尋的地方筆記。
- `/stories/a-station-in-daily-life/`：車站文史入門；可回到文資處來源。
- `/stories/a-place-to-stop/`：空間與願景的編輯整理，無虛構採訪或署名。
- `/walk/2026/`：延續兩日切換、節目、市集、護照、地圖、合作單位與報名狀態。
- `/exhibition/to-and-from/`：四章錨點、展覽材料與原有 PDF 連結。
- `/visit/`：正確地址、交通、開放狀態與周邊地點導航。

原有三個主路徑不變。修正合作單位圖片與主辦首頁連結漏加 `/rinan-commons` 的問題。

## 資料決策

現有 `db/schema.ts` 原為空，`.openai/hosting.json` 的 D1/R2 為 null。此回合不把原 ChatGPT Site 當成新資料後端。

建立可重現的 SQLite 內容資料庫：SQL 版本來源 → SQLite 驗證 → 公開 JSON 快照 → Next 靜態輸出 → GitHub Pages。它是**建置時內容資料庫**，不是已開通的即時雲端資料庫。

每筆資料包含 id、kind、status、source、updated_at、sort_order 與 JSON payload。支援設定、文章、章節、材料、節目、店家、地點、組織、演出與空間功能。資料來源與狀態保留在 SQL；前台只匯出 published。

原有邀請中攤商與缺乏本次公開確認依據的演出名單保留為 draft。既有已確認攤商與指導／主辦名單沿用原 repository 基線。這不是重新確認合作；主辦應持續核對正式書面紀錄。

此 repository 本身為 public，draft 僅代表不進入前台，**不構成保密權限**。原先已公開的規劃資料保留版本記錄；不得新增私人電話、報名者個資、內部合作文件或金鑰。
