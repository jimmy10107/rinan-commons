# 日南九里互動地圖

2026-09-15：加入 `/visit/#rinan-map` 及獨立 `/maps/`；活動頁附入口。

`public/maps/boundaries.json` 完整保留使用者上傳 HTML 的 DATA，包含九里、外圍界線、中心、範圍、面積與周長。未新增或重繪座標。原檔標示來源為國土測繪中心村里界（2021），未獨立查證為最新行政界線。

獨立 HTML 以 iframe 隔離 Leaflet 樣式。Leaflet 1.9.4 本地保存，授權位於 vendor/LICENSE；底圖仍需連線 Esri。此地理參考資料為公開靜態 JSON，不存入報名資料表，也未啟用雲端資料庫。

桌面控制欄不遮擋地圖；小螢幕控制欄預設收合，可展開使用全部九里控制。滾輪缩放預設關閉，避免干擾閱讀，可主動啟用。支援勾選、定位、透明度、底圖切換、全區復位及鍵盤地圖控制。

底圖失敗保留里界並提供重試。獨立入口可避免小螢幕嵌入框內捲動。
