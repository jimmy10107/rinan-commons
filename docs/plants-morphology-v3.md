## Fact / 交付行為

- 名稱：日南植物形態室；URL 維持 /plants/，所有舊連結仍可使用。
- 原 42 GLB 全保留，增加 36 份輕量衍生模型：30 全株＋6 特寫。預設芋頭旺盛生長第一層 158688 bytes。
- 自動：先 128px 紋理／簡化網格，再補載原 512px 網頁模型；器官特寫放大超過約 1.45 倍時補載原 1024px 精細版本。亦可手選輕量、細緻、精細。
- 替換模型前完成解析與材質編譯，保留現有模型可操作；同種同模式升級保留使用者相機位置、縮放與平移。約 420ms 線性淡入，減少突兀；尊重 reduced-motion。
- 甜根子草的銀白細毛使用深色底提高對比；所有植物皆可切換深淺背景。保留網格、逆光、旋轉、PNG 與 GLB 下載。
- 官網其他頁 load 完成且 5 秒無輸入後，串行下載六份輕量模型，總計 1161072 bytes；每份之間再留 5 秒。捲動、觸控、按鍵、離屏會中止／延後。
- Cache Storage 只存此功能的輕量 GLB，跨完整頁面導覽重用；不使用全站 Service Worker。WebGL、Three.js 不在其他頁初始化。
- Save-Data、2G／3G 連線停用預載及自動精細升級；仍直接提供輕量 3D，可手動選細節。瀏覽器無網路狀態 API 時按一般連線處理。
- Cache Storage 不可用時回退正常 HTTP 請求；精細載入失敗保留當前模型；首次失敗提供預覽、重試與下載。既有離屏停止繪製、收起釋放 GPU 均保留。

## Risk / 限制與維護

- 沒有新增實株掃描或重新製作高精度幾何；材質與生物學限制依 v2 說明，不能把本次 UX 改善宣稱為新的照片級掃描。
- 全株升級上限為原 v2 網頁模型；器官精細樣本與生長階段不是同一幾何，不在全株縮放時偷偷切成另一株。
- 分級模型固定網址更新時，須升級 model-cache.ts 的版本名稱以避免舊快取。
- 生成：node scripts/build-plant-lites.mjs；需要 npm ci。葉片有大量獨立曲面，誤差限制不保證每份都達到同一三角面數；以實際 bytes 與瀏覽器顯示驗收。
- 驗證是 Chromium 軟體 WebGL 和手機視窗模擬，不是實體 iOS／Android 裝置。所有狀態檢查與快取證據見 docs/qa/plants-v3。
