## 本次授權與邊界

使用者明確要求全部整合、加入官網選單並部署至 GitHub。目標是 jimmy10107/rinan-commons 的 main／GitHub Pages，基線 08097b4；不是 ChatGPT Sites 的 rinan-walk。既有活動內容、地圖與私人媒體服務均維持原本用途。

本次公開的是網頁展示衍生檔：42 個壓縮 GLB（30 全株、6 流暢特寫、6 精細特寫），42 張模型預覽（30 全株與六種器官各兩種尺寸），28 張照片＋1 張圖示的展示版本與完整署名。原始 Blender 製作包、未公開照片、帳戶資料與任何私人檔案索引不進入官網。

新增圖片已依本次「全部整合並部署」授權，逐檔加入 public-image-allowlist.json 的 SHA-256；沒有放寬既有私人媒體檢查。後續替換素材仍會觸發原來的檢查。

## 體驗與效能

- 起始頁呈現清晰的模型渲染與可讀文字；零 GLB 請求，Three.js 與解碼器在啟動 3D 後才匯入。
- 點植物只看該種；一次保留一個模型。切換取消上一個 fetch，過期解析結果會釋放。
- 36 個基本觀察狀態均有預覽，沒有 WebGL 也可瀏覽；各物種的五階段名稱分開，沒有虛構等長生理時間。
- 手機預設 balanced（512px 貼圖、簡化幾何）；器官提供明確的精細選項（1024px）。介面標示每次模型的下載大小。
- Meshopt 幾何壓縮＋WebP 貼圖。已在實際瀏覽器讀取全部 42 個 GLB；單檔資料見 plants-asset-budget.json。
- 預設不自動旋轉。靜止、畫面外、分頁隱藏時停止繪製；收起 3D 釋放幾何、材質、影像與 WebGL context。
- 手機像素比上限 1.25，桌面 1.5；持續移動慢幀時可下調至 1。沒有將此策略冒稱為所有手機的固定幀率保證。
- 第一次材質編譯完成後才顯示可操作狀態；on-demand rendering 明確 flush GPU 指令，避免空白畫面。
- 正面／背面／側面、縮放、逆光、旋轉均有按鈕，鍵盤也能操作。生長切換緊接模型，手機無需先越過長段文字。
- 獨立錯誤與重試：網路失敗、WebGL context 遺失仍保留預覽；重試會建立新的 context。
- 參考圖區預設收合，展開才建立圖片；逐張署名與授權連結。下載目前 GLB 或 PNG 需使用者點選。
- 360／390／768／1024／1440 寬度測試；1120px 以下使用可展開選單，避免增加頁面後桌面導覽擠壓。

## 來源與真實程度

模型源自此前交付的 v2 美術重建，包含生成材質，並非日南實株攝影測量。全株與器官是不同精細度的資產，尚未逐株或逐品種校準。公開頁面保留此說明。

本次另補齊兩張公有領域圖片的機器可讀 metadata 缺漏：Scott Bauer 的 USDA 甜根子草照片，以及 Yug 自行拍攝並釋出的構樹果序。後者原作者曾註記物種辨識未定，介面也保留該限制。逐筆修正見 content/plants-reference-corrections.json。

## 驗證與維護

`npm run build:pages` 執行 TypeScript、內容、公開媒體與靜態輸出；`npm run test:pages` 檢查 10 個公開頁、basePath、內部連結及未公布名單隔離；`npm run test:plants` 檢查 42 個自包含 GLB、檔案預算、預覽與來源。既有內容／媒體服務測試照常執行。

`tests/browser-plants.mjs` 使用 Playwright（選用）與實際匯出的 out；可設定 PLAYWRIGHT_MODULE、CHROMIUM_PATH，也可指定 PLANTS_BASE_URL 測正式網址。結果與截圖在 docs/qa/plants。慢網路測試為 390px、1.6 Mbps、150ms latency、4 倍 CPU 降速的瀏覽器模擬；不是 iPhone 實機量測。

重新匯出需要原始 v2 製作包：`node scripts/build-plants.mjs /path/to/v2-production-pack`，再以 `scripts/render-plant-stages.cjs` 產生三十種全株預覽。材質或預覽改變後仍需人工確認衍生素材及更新逐檔核准雜湊，不能自動擴大公開範圍。
